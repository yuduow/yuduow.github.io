# Article figure fonts

Outfit Article is a pair of static font faces (weights 400 and 600) derived from the website's existing `outfit-latin.woff2` using FontTools. The family was renamed so Matplotlib selects these faces reliably. The figures embed glyph outlines in SVG and rasterize the same faces for PNG; readers do not need the fonts installed.

The fonts retain Outfit's SIL Open Font License; see `OFL.txt`. Keep this directory beside `article_figures.py` when reproducing the figures.
