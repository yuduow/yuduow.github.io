Notes

Memory Names Are Easy to Mix Up

CUDA local memory is private to a thread. Intel SLM and Metal threadgroup memory are shared within a group. Metal private resource storage controls CPU access.

Hardware Counts Are Not Interchangeable

SM, CU, Xe-core and shader core describe different hardware organizations. Their counts do not measure equal amounts of compute.

Use the API’s Synchronization Rules

A subgroup does not guarantee implicit synchronization. Barriers, shuffles, atomics and queues each have participation and ordering rules.
